# Dr.STONE 勉強50日チャレンジ

中学生が宿題以外に毎日1問以上、自主勉強を続けるためのスタンプアプリです。
解いた日ごとにキャラクターが1人ずつ登場し（50位→1位）、問題数に応じてスタンプが銅・銀・金・プラチナへ変化します。

- 公開URL: https://alochan-python.github.io/dr-stone-study-quest/
- 非公式の個人用アプリです。原作の権利は各権利者に帰属します。
- キャラクター画像は暗号化して配信しています。各端末で1回、合言葉を入れると表示されます（[画像の扱い](#画像の扱い)）。

## 使い方

1. ホーム画面で「＋1問」「＋5問」を押して、宿題以外に解いた問題数を入れる
2. 宿題が終わっていれば「宿題を終えた」にチェックする
3. 「今日の記録を保存」を押す（確定音が鳴ります。音は「きろく」タブでオフにできます）

| 問題数 | スタンプ |
| --- | --- |
| 0問 | なし（キャラクターは進まない） |
| 1問 / 2問 / 3問 | 銅 / 銀 / 金 |
| 4問 | プラチナ |
| 5問以上 | プラチナ＋（問題数−3）。例: 5問＝＋2、10問＝＋7 |

- キャラクターは1日に1人まで。同じ日に問題数を増減すると、同じキャラクターのグレードだけが変わります。
- 宿題だけの日はキャラクターが進まず、連続日数にも入りません（宿題日数には数えます）。
- 1日休むと連続記録は途切れますが、獲得済みのキャラクターは残り、次のキャラクターから再開します。
- 過去の記録は「カレンダー」か「スタンプ帳」から修正できます。キャラクターの割り当ては達成日の順に毎回計算するので、抜けや重複は起きません。達成・未達成が変わる修正では、以降の日のキャラクターが1人ずつずれます（保存前に確認が出ます）。
- 50人そろうと記念画面が開きます。51人目から次の文明レベルに進みます（石器時代のレベル1から宇宙開発のレベル7まで）。前のレベルの記録は消えません。レベル7のあとは、レベルは7のまま周だけ増えます。
- 連続で20日達成するたびに、お助けアイテムを1個もらえます。日数は「きろく」の「管理」で1〜100日に変更できます。休んだ翌日にホームのボタンで使うと、休んだ日も連続がつながります（1日につき1個。使った日は連続日数に足しません。キャラクターも進みません）。翌日を過ぎると使えません。1問以上に直すか未入力に戻すと、アイテムは戻ります。
- 日付はすべて日本時間（Asia/Tokyo）で判定します。

## 起動方法

Node.js 22 以上が必要です。

```bash
npm install
npm run dev        # 開発サーバー → http://localhost:5173/dr-stone-study-quest/
npm test           # Unit / Integration テスト
npm run build      # 本番ビルド
npm run preview    # ビルド結果の確認 → http://localhost:4173/dr-stone-study-quest/

npx playwright install chromium webkit   # 初回のみ
npm run test:e2e                         # E2Eテスト（先に npm run build）
BASE_URL=https://alochan-python.github.io/dr-stone-study-quest/ npx playwright test   # 公開版に対して実行
```

## iPhone / iPad のホーム画面に追加する

1. **Safari** で公開URLを開く
2. 共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
3. ホーム画面のアイコンから起動する

一度開いたあとは、インターネットに接続していなくても起動・記録できます。
Android の Chrome では、メニューの「ホーム画面に追加」から同様に追加できます。

iPhone / iPad の消音モード（着信スイッチ）がオンの間は、確定音が鳴らないことがあります。

## データのバックアップ

「きろく」タブから操作します。

- **書き出し**: 「JSONに書き出す」でファイルを保存します（iPhone では共有シートから「ファイルに保存」やAirDropを選びます）。
- **復元**: 「JSONから復元」でファイルを選ぶと、追加される日数と内容が違う日数を確認できます。
  - 足りない日だけ追加（標準）: 今の記録は変わりません。
  - 全部置き換える: 確認のうえ置き換えます。直前の状態は控えとして1回分残り、「この状態に戻す」で戻せます。
- **初期化**: 「リセット」と入力しないと実行できません。

## データ保存の制約

- 記録はブラウザの IndexedDB に保存します。サーバーはなく、記録が外部に送信されることはありません。
- **端末間の自動同期はありません。** 端末を移るときはバックアップと復元を使ってください。
- 別のブラウザや、同じ端末の Safari とホーム画面アプリでは、データが別々になる場合があります。ふだん使う入口を1つに決めてください。
- Safari で開いているだけのサイトは、しばらく使わないと保存データが消されることがあります。**ホーム画面に追加して使い、定期的にバックアップしてください。**
- ブラウザのサイトデータを消去すると記録も消えます。

## 画像の扱い

提供されたランキング画像は個人利用が前提で、再配布の許諾を得たものではありません。そのため、GitHub には**暗号化した状態でのみ**置いています。

| 種類 | 置き場所 | 公開 |
| --- | --- | --- |
| 仮画像（順位と頭文字を描画） | アプリ本体 | する |
| 暗号化した画像（AES-256-GCM） | `public/packs/characters.enc.json` | する（合言葉なしでは見られない） |
| 提供画像・切り出し画像・画像パック・合言葉 | `private-assets/`（`.gitignore` 済み） | **しない** |

各端末で1回、ホーム画面に合言葉を入れるか、公開URLの末尾に `#key=合言葉` を付けたリンクを開くと、画像を取得・復号して端末内に保存します。以後はオフラインでも表示できます。

iPhone / iPad では、Safari とホーム画面のアプリで保存場所が別になる場合があります。ホーム画面のアプリに画像が出ないときは、アプリのホーム画面で合言葉を入れてください。

- **合言葉や合言葉つきリンクを公開の場所に書かないでください。** 家族など、使う人にだけ直接伝えてください。
- 暗号化は第三者に見えないようにする仕組みで、権利上の許諾に代わるものではありません。あくまで個人利用の範囲で使ってください。
- 合言葉を変える場合は `private-assets/passphrase.txt` を書き換えて `npm run pack:encrypt` を実行し、push します。

### 画像を作り直す

1. `private-assets/source/` に提供画像を置き、`npm run pack:images` を実行する（Python と Pillow が必要）
2. `npm run pack:encrypt` で暗号化する

Mac で `npm run dev` を使う場合は、`private-assets/dr-stone-image-pack.json` があれば自動で実画像を表示します（ローカル起動の時だけ動きます）。

一部の順位だけ差し替えることもできます。次の形式のJSONを「きろく」タブの「画像パックを読み込む」で選ぶと、含まれる順位だけ置き換わります（WebP / PNG / JPEG）。

```json
{ "app": "dr-stone-study-quest", "type": "image-pack", "version": 1, "images": { "50": "data:image/webp;base64,..." } }
```

`npm run check:assets` は、Git管理下と `dist/` に暗号化していない提供画像が混ざっていないかを検査します。デプロイ時にも自動で実行し、見つかった場合は公開を中止します。

## GitHub 公開手順

`main` ブランチへ push すると、GitHub Actions がテストとビルドのあと GitHub Pages へ自動で公開します。新しいリポジトリに一から設定する場合は次のとおりです。

```bash
gh repo create dr-stone-study-quest --public --source=. --push
gh api -X POST repos/{owner}/dr-stone-study-quest/pages -f build_type=workflow
```

別の名前のリポジトリで公開する場合は、`vite.config.ts` の `base` も変更してください。
